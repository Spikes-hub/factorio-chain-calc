# История изменений

[English](CHANGELOG.md) · **Русский**

Здесь перечислены заметные изменения, новые сверху. Формат: версия — дата.

## Не выпущено

- Блюпринты: генератор прокладывает трубы и подземные трубы для входов и выходов по жидкостям, умеет заводы с жидким топливом (разворачивает так, чтобы порт топлива смотрел на трубу), несколько раскладок, выученных по шаблонам, собранным вручную (литьё с погрузчиком, ацетилен, битум, креозот, стекольный завод, дистиллятор, зеркальные пары с зазором в одну клетку), и схему раскладки. Если для завода рецепта ещё нет образца раскладки, генератор отказывает фразой «нет образца раскладки труб» вместо догадки; сними галочку «трубы», чтобы получить блок без труб. **Сделай новый дамп** после обновления: вход топлива у заводов с жидким топливом читается из геометрии.
- Блюпринты: заводы могут стоять зеркально (поле `mirror` из Factorio 2.0), поэтому порты обоих столбцов блока оказываются на одних рядах; проверка труб идёт строго по правилам игры (подземная труба подключается только устьем и к ближайшей встречной), а блок, в котором трубы смешали бы две жидкости одного завода, не выдаётся, а отклоняется; порядок портов берёт сначала порт на противоположную стену, и лишь потом порты, смотрящие вдоль стенки; заводам с портами по центру всех четырёх стен (теплообменник) между каждыми двумя заводами оставляется зазор в один тайл, и жидкости идут через зазоры.
- Этапы без твёрдых входов (сырьё только по трубам) режутся на группы по ленте выхода, и поле ручного размера «заводов в группе» показывается и для них.
- Поддержка мода Train ETA: в настройках галочка «я использую мод» (там же название, ссылки на GitHub и на сайт мода), и над маяками появляется раздел «Поезд». Для каждого ресурса вкладки вводится время в пути (мин:сек, в одну сторону, круг считается ×2) и считается, сколько везти за рейс, чтобы блок не простаивал, с запасом +30%; скорости погрузки и разгрузки задаются в настройках (по умолчанию 60 и 60), жидкости грузятся мгновенно и считаются в литрах, топливо считается отдельно.
- Рядом с «заводов в группе» появилось поле «групп»: вводишь число групп, и заводы делятся поровну (ввод в одно поле очищает другое; число ограничено числом заводов этапа).
- Заводы, у которых единственный вход жидкости сквозной (экстрактор грунта: два противоположных устья «вход-выход»), ставятся в столбец вплотную; жидкость подводится только к верхнему заводу и идёт дальше сквозь остальные.
- Поиск рецептов и окно «Как получить» показывают завод, в котором делается рецепт, прямо под названием рецепта.
- `start.bat`: Ctrl+C останавливает сервер без вопроса «Terminate batch job (Y/N)?».
- В выпадающих списках (заводы, топливо, маяки, этапы, сохранённые цепочки) показаны иконки; пепел от сожжённого топлива выходит на отдельную ленту.
- В документации указана версия игры, с которой проверялся дамп: Factorio 2.0.77 (набор Pyanodon, версии модов в README).
- Группы рецептов: побочка, которую возвращает вкладка ниже по цепочке (например, отходы гидроциклона, который ест предмет группы), теперь целиком уходит участнику группы, который её перерабатывает, с округлением вверх до целых заводов; остальные участники покрывают остаток. Цикл ищется по всей цепочке до головной вкладки.
- В строках подачи при нескольких группах подачи рядом со значением «на группу» показана общая сумма по этапу.
- Одноимённые рецепты различаются по входам («— из: ...») в окне выбора рецепта, в подсказках вкладок и в сводке группы, а не по внутреннему id.

## 0.1.0 — 2026-10-06

Первый публичный релиз.

- Калькулятор производственных цепочек: заводы, модули, маяки, продуктивность, петли, топливо и зола горящих заводов.
- Ленты, жидкости, манипуляторы и погрузчики; вкладка *Манипуляторы* с галочками (в дампе из сохранения стоят у
  изученных, в полном дампе — ни у кого), настройки сохраняются между дампами, а вручную настроенные строки
  можно обновить до нового дампа.
- Генерация блюпринтов раскладки блока.
- Сундук запроса на всю цепочку; сундук запроса по любому вставленному блюпринту; «Сборщики всего».
- Поиск рецепта по названию, продукту, ингредиенту или id.
- Дампы: `dump_full.bat` (все рецепты + геометрия) и `dump_from_save.bat` (ещё и что изучено); названия на языке
  игры; иконки и геометрия кэшируются по набору модов.
- Интерфейс на русском и английском, тёмная тема, вёрстка для телефона.
