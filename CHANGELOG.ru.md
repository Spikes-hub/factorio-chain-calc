# История изменений

[English](CHANGELOG.md) · **Русский**

Здесь перечислены заметные изменения, новые сверху. Формат: версия — дата.

## 0.2.0 — 2026-10-10

### Крупные изменения

- **Трубы в блюпринтах.** Генератор блока прокладывает трубы и подземные трубы для входов и выходов по жидкостям,
  умеет заводы с жидким топливом и строит раскладки, выученные по шаблонам, собранным вручную (литьё с погрузчиком,
  ацетилен, битум, креозот, стекольный завод, дистиллятор, теплообменник, реактор псевдоожижения, зеркальные пары с
  зазором в один тайл). Перед копированием строки показывается схема раскладки. Если для завода рецепта ещё нет образца
  раскладки, генератор не гадает, а отказывает понятным сообщением: сними галочку «трубы», чтобы получить блок без
  труб. Рецептов, которые генератор не строит, стало 67 вместо 215.
  **После обновления сделай новый дамп**: вход жидкого топлива у заводов читается из геометрии построек.
- **Зеркальные заводы и более строгая проверка труб.** Заводы могут стоять зеркально (поле `mirror` из Factorio 2.0),
  подземная труба подключается только устьем и к ближайшей встречной, как в игре, а блок, в котором трубы смешали бы
  две жидкости одного завода, не выдаётся, а отклоняется. Заводам с портами по центру всех четырёх стен между
  заводами оставляется зазор в один тайл; единственный сквозной вход жидкости (экстрактор грунта) подводится только к
  верхнему заводу столбца.
- **Поддержка мода Train ETA.** В настройках галочка «я использую мод» (там же название, ссылки на GitHub и на сайт
  мода), и над маяками появляется раздел «Поезд»: для каждого ресурса вкладки вводится время в пути (мин:сек, в одну
  сторону, круг считается ×2) и считается, сколько везти за рейс, чтобы блок не простаивал, с запасом +30%. Скорости
  погрузки и разгрузки задаются в настройках (по умолчанию 60 и 60), жидкости грузятся мгновенно и считаются в литрах,
  топливо считается отдельно.
- **Группы рецептов.** Побочка, которую возвращает вкладка ниже по цепочке (например, отходы гидроциклона, который
  ест предмет группы), целиком уходит участнику группы, который её перерабатывает, с округлением вверх до целых
  заводов; остальные участники покрывают остаток. Этапы без твёрдых входов режутся на группы по ленте выхода, а
  рядом с «заводов в группе» появилось поле «групп» (ввод в одно поле очищает другое).

### Мелкие изменения

- Исправлены мелкие баги, доработан интерфейс.

## 0.1.0 — 2026-10-06

Первый публичный релиз.

- Калькулятор производственных цепочек: заводы, модули, маяки, продуктивность, петли, топливо и зола горящих заводов.
- Ленты, жидкости, манипуляторы и погрузчики; вкладка *Манипуляторы* с галочками (в дампе из сохранения стоят у
  изученных, в полном дампе — ни у кого), настройки сохраняются между дампами, а вручную настроенные строки
  можно обновить до нового дампа.
- Генерация блюпринтов раскладки блока.
- Сундук запроса на всю цепочку; сундук запроса по любому вставленному блюпринту; «Сборщики всего».
- Поиск рецепта по названию, продукту, ингредиенту или id.
- Дампы: `dump_full.bat` (все рецепты + геометрия) и `dump_from_save.bat` (ещё и что изучено); названия на языке
  игры; иконки и геометрия кэшируются по набору модов.
- Интерфейс на русском и английском, тёмная тема, вёрстка для телефона.
